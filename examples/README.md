# Examples

## Required tree-label format

Use original species names in the species tree and append an underscore plus a copy ID in every gene tree:

```text
Species tree leaf: SpeciesName
Gene tree leaf:    SpeciesName_copy
```

Example:

```text
Species tree: ((Homo_sapiens,Pan_troglodytes),Mus_musculus);
Gene tree:    ((Homo_sapiens_copy1,Mus_musculus_copy1),Pan_troglodytes_copy1);
```

Copy IDs are preserved exactly. Species names may contain underscores because matching uses the longest species-tree name followed by `_`.

## Single-tree CLI

```bash
reconcils \
  --sp_file examples/spTree.tre \
  --gt examples/gTree.tre \
  --output results.csv
```

The launcher detects files automatically; do not pass `--F`. Add `--verbose 1` for DAFT-style Rich validation panels and a final result summary.

reconcILS automatically maps sorted species names to fixed two-character internal IDs, runs the legacy engine with labels such as `A0_copy1`, and restores the result to `SpeciesName_copy`. The generated map is `results_species_aliases.json` unless `--alias-output` is supplied.

## Parameterized parallel runner

`parallel_reconciliation.py` has no embedded species tree, accession list, simulation dataset, or truth-label table.

```bash
python examples/parallel_reconciliation.py \
  --species-tree /path/to/species.tre \
  --gene-trees /path/to/gene_trees.tre \
  --output /path/to/reconcILS_result.csv \
  --workers 4
```

The species-tree file must contain exactly one semicolon-terminated Newick tree. The gene-tree file may contain any number of semicolon-terminated trees, one per line or separated by whitespace. Every gene leaf in every tree must be `SpeciesName_copy`.

### Fully explicit run

```bash
python examples/parallel_reconciliation.py \
  --species-tree /data/species.tre \
  --gene-trees /data/gene_trees.tre \
  --output /results/reconcILS_result.csv \
  --labeled-species-output /results/reconcILS_labeled_sp.csv \
  --alias-output /results/reconcILS_species_aliases.json \
  --state-dir /results/reconcILS_state \
  --mapping /data/species_aliases.tsv \
  --species-format 1 \
  --gene-format 1 \
  --duplication-cost 1.1 \
  --loss-cost 1 \
  --ils-cost 1 \
  --workers 8 \
  --library-threads 1 \
  --checkpoint-every 100 \
  --progress-every 30 \
  --poll-interval 0.05 \
  --ils-timeout 600 \
  --timeout 1800 \
  --verbose 1 \
  --worker-logs
```

Use `python examples/parallel_reconciliation.py --help` for all options.

### Mapping behavior

Without `--mapping`, aliases are generated from species names sorted lexicographically:

```text
first species  -> A0
second species -> A1
...
```

All aliases are exactly two uppercase letters/digits and never contain `_`, so they cannot be confused with one-letter event symbols or the copy separator. The namespace supports up to 1,296 species.

An optional JSON/CSV/TSV mapping can provide selected or all aliases. CSV/TSV columns are `species,alias`; JSON may be a direct object or a mapping report previously generated by reconcILS.

The alias-output JSON contains:

- `original_to_internal`;
- `internal_to_original`;
- species count;
- ordering and alias-scheme metadata;
- the required `SpeciesName_copy` convention.

### Rich progress dashboard

With `--verbose 1`, the parent process displays total and processed gene trees, saved rows, active workers, failures, checkpoint rows, elapsed/estimated time, output path, and state directory. Worker output remains in per-tree logs so the dashboard stays readable.

### Outputs and resume behavior

The runner writes:

- the ordered result CSV requested with `--output`, using original labels;
- the aggregated event-labeled species tree, also using original labels;
- the species/copy mapping JSON;
- a checkpoint journal, lock file, and failure logs in `--state-dir`.

Rerunning the same command resumes from the journal. The journal rejects changed trees, mappings, costs, formats, or algorithm code. Use `--retry-failed` to retry a failed tree.

### Common validation errors

`Gene leaf 'Homo_sapiens' is missing a copy ID` means the leaf must be renamed, for example, to `Homo_sapiens_copy1`.

`Gene leaf 'Unknown_copy1' does not match any species-tree leaf` means `Unknown` is absent from the species tree.

Duplicate full copy labels such as two leaves both named `Homo_sapiens_copy1` are rejected; use distinct copy IDs.

### Timeout controls

`--ils-timeout` sets the internal ILS search timeout (default 5000 seconds); `--timeout` sets an optional hard per-gene-tree worker timeout (default: no outer limit). The outer timeout can kill a worker, whereas the internal `ThreadPoolExecutor` timeout does not forcibly stop a running thread. The internal timeout is recorded in checkpoint metadata. Use `--timeout` for an enforceable per-tree wall-clock limit.

### DAFT-style result folders

The parallel example writes results into `reconcILS_results_<output stem>/`,
its alias map into `reconcILS_extras_<output stem>/`, and resumable checkpoints
and worker logs into `reconcILS_log_<output stem>/`. Reuse the same `--output`
when resuming a run.
